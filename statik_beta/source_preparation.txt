ORIGINAL PLAN (retained for traceability)

The source candidate is separate from the working development checkout.
tools/snapshot_statik_source.ps1 copies Git-enumerated source, including recursive
dependency contents and explicitly selected local additions. It does not copy
the workspace wholesale, Git history, game/firmware directories or toolchains.
Every exported file has a SHA256 entry in source_manifest.json. Excluded tracked
binary/archive/PDF files are listed separately and require review for build impact.

- Existing build script: tools/build-wipeout.ps1. This currently assumes a local
  tools/llvm installation and VS Community; it is NOT yet a portable release recipe.
