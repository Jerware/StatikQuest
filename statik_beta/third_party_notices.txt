The emulator statically links many third-party components including Khronos
OpenXR, SDL3, FFmpeg, OpenAL Soft, libusb, FDK-AAC, FreeType, LibreSSL,
Dear ImGui, ImGuiFileDialog, glslang, sirit, Zydis/Zycore, zlib-ng, libpng,
LibAtrac9, spdlog, fmt, Tracy, miniz, miniupnpc, pugixml, hwinfo, xxHash and wepoll.
The notices directory, when assembled with -NoticeDirectory, contains 130
original notice/source files and a hash manifest. This includes a superset of
source dependencies, font metadata, and notices embedded in selected headers.
The LLVM 21.1.8 compiler-runtime license is included too.
It is not a completed component-by-component license clearance. See the source
companion for FFmpeg patches, upstream source archives and build configuration.

FDK-AAC's custom license needs a compatibility review before distribution.
The user has chosen to retain this inherited decoder; this is not a licensing
exception. LibreSSL also retains legacy OpenSSL/SSLeay terms needing review.
FFmpeg's prebuilt source/configuration and the static LGPL dependencies need
matching source and rebuilding/relinking materials as applicable.
FFmpeg's actual configuration was extracted from avcodec.lib: it disables
libfdk-aac; the emulator separately links FDK-AAC. These are distinct components.
